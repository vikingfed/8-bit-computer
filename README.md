# Сборка 8-битного компьютера

Статус проекта: в процессе (тактовый генератор отлично отрабатывает; есть два регистра; собрано АЛУ).
Я собираю 8-битный компьютер на платах, опираясь на видео из YouTube автора Ben Eater. Оставляю и буду оставлять этапы сборки.

## Более подробное описание компонентов
Тактовый генератор:
- В основе - 555 timer;
- Два режима - автоматическая генерация тактов с регуляцией частоты и ручная по нажатию кнопки;
- Переключение между режимами через кнопку.

Регистры:
- Два регистра, у каждого есть вывод через LEDs, показывающие текущие 8-битные данные в регистрах;
- В основе хранения 4-битная интегральная схема SN74LS173 (2 штуки для каждого регистра);
- Выход на шину контролируется через SN74LS245.

Арифметико-логическое устройство:
- Поддержка сложения и вычитания;
- Вычитание происходит за счет прогона через схемы DM74LS86, которые делают значение регистра В (нижний на фото) отрицательным;
- Логика арифметики - SN74LS283;
- Выход на шину контролируется через SN74LS245.

## Что добавила
- Добавила временную имитацию шину данных сбоку, в основном для траблшутинга работы регистров и АЛУ.

## Что исправила
- Исправила наконец-то основную проблему с питанием. Решение оказалось очень неожиданным, я к нему пришла методом тыка: на моих макетных платах на середине обрывается контакт (они видимо слишком длинные), потому нужно дополнительно посередине VCC и GND между собой соединять. Сделала это - все заработало;
- Далее была проблема с перепутанными проводами в блоке АЛУ: порядок входов в сумматор 74LS283 был перепутан. Тут помогла внимательная работа с даташитами микросхем;
- По мелочам: исправила положение одной микросхемы 74LS86 (там одна ножка погнулась и не работала), заменила несколько светодиодов, которые перестали работать.

## Проблемы 
- Пока все, что было, исправила.

## Наблюдения
- Когда начинала собирать этот компьютер по видео из ютуба, думала, что это будет как сборка лего по инструкции. То есть если все делать верно и как написано в инструкции, то у тебя все будет хорошо работать. Оказалось, это совсем не так с электроникой. Нужно опираться на видео только как на визуальную идею и пример архитектуры. За кадром остается работа с документацией, мультиметром, кропотливый поиск проблем, внимание к деталям.
